Анализатор пакетов

Анализ пакетов (протоколов) описывает процесс перехвата и интерпретации действующих данных по мере их продвижения по сети. Как правило, анализ пакетов проводится анализатором пакетов (сниффером) - инструментальным средством, применяемым для перехвата первичных данных, передаваемых по проводам сети.

Принцип действия анализаторов пакетов:

  1. Сбор двоичных данных из сети через смешанный режим (promiscuous mode) в сетевом интерфейсе (в этом режиме принимается весь трафик в сегменте сети, а не только адресуемый).
  2. Двоичные данные преобразуются в удобочитаемую форму.
  3. Анализатор пакетов проводит анализ перехваченных и преобразованных данных. В частности, он проверяет протокол перехваченных в сети данных, исходя из извлекаемой информации, и далее начинает анализ характерных особенностей этого протокола.

Известные анализаторы пакетов:

  • tcpdump;
  • WireShark.

Список инструментов для анализа пакетов

  • CloudShark - решение для хранения, индексирования и сортировки перехваченных пакетов.
  • WireEdit позволяет редактировать значения в отдельных полях пакета. Нужная вещь, чтобы протестировать применяемую систему обнаружения вторжений или разработанное сетевое программное обеспечение.
  • Cain & Abel - устаревшая программа, используемая для заражения АRР-кеша.
  • Scapy - библиотека на языке Pythoп, с помощью которой можно создавать пакеты и манипулировать ими по сценариям из командной строки.
  • TraceWrangler делает в перехваченных пакетах более анонимными различные типы присутствующих в них адресов.
  • Tcpreplay осуществляет повторную передачу, чтобы посмотреть, как на них будут реагировать сетевые устройства.
  • NetworkMiner применяется для судебной экспертизы сетей и включает, например, синтаксический анализ пакетов, извлечение переданных файлов.
  • CapTipper предназначено для специалистов по безопасности сетей, занимающихся анализом сетевого трафика по протоколу НТТР, а именно поиск переадресации, файловых объектов и зловредного содержимого.
  • ngrep позволяет находить конкретные данные в перехваченных пакетах.
  • hping служит для обработки, правки и передачи пакетов в режиме командной строки.
