#  Root Path

Мои конспекты по сетям, оформленные в виде [сайта](https://a75bcd15.github.io/root-path/).

- Структура репозитория:
``` bash

root-path
├── docs                # хранилище конспектов
│   ├── index.md        # навигация по блокам
│   ├── net             # блок по основам сетей
│   │   ├── etc
│   │   ├── index.md    # оглавление по сетям
│   │   ├── md          # заметки по сетям
│   │   └── pic
│   └── voip            # блок по телефонии
│       ├── etc
│       ├── index.md    # оглавление телефонии
│       ├── md          # заметки по телефонии
│       └── pic
├── mkdocs.yml          # конфиг генератора сайта
└── README.md           # вы читаете это здесь ;)

```
